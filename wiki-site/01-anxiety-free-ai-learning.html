課程理念:用原理對抗焦慮

  • 課程特色有二:「用原理對抗焦慮」與「教 AI 用你的方法做事」。S01 p.38
  • 了解原理才能沒有焦慮、好好應用,並成為 AI 學習的強者;註記「原理的確有包括數學」。S01 p.39
  • 焦慮 1「我是不是會被 AI 取代?」:「AI 是不是比我還要厲害?」,並引述常聽到的「會取代你的是會用 AI 的人」。S01 p.40
  • 焦慮 2「發展這麼快,我是要怎麼學?」:每天都有新工具,不知道哪個最好;懂得原理後會發現語言模型只是一個呆萌型 AI 機器人,大型語言模型的基礎模型是差不多的。S01 p.41
  • 焦慮 3「學 AI 感覺好難」:AI Agent 其實只是「教 AI 做事的方法」。投影片以分層圖列出:Chat Bot 涵蓋 Prompt Engineering、Contex(原文拼法)Engineering;AI Agent 涵蓋 Harness Engineering、Loop Engineering、Graph Engineering(Context Engineering 位於兩個範圍交界處)。S01 p.42
  • 學習目標:(1) 知道原理就知道 AI 的限制並思考怎麼突破;(2) 應用上不太擔心 A 模型是不是比 B 模型強,而是怎麼找適合自己的模型;(3) 知道為什麼這樣的引導(prompt)會有好處;(4) 變成學習 AI 能力非常強的人,成為強大的「吸收器」。S01 p.43
  • 學習內容:神經網路(目前最火紅的 AI 技術)、GAN(「傳統」生成式 AI 的想法)、LLM 大型語言模型(原理、RAG、AI Agent)、圖形生成的 AI:Diffusion Models、實作技巧。S01 p.44

AI 模型只是「輸入 → 輸出」

  • 現代的 AI 模型只是一個呆萌型 AI 機器人:不會自己知道要做什麼,需要我們告訴它輸入是什麼、輸出是什麼;不會分析、沒有意識、不知道自己在做什麼。呆一布(DIVE)是政大「呆一布 AI 實驗室」的吉祥物。S01 p.45
  • 八哥辨識範例:在野外拍到一隻八哥,想知道是什麼八哥;輸入一張照片,輸出「(土)八哥」;模型以 f_θ 表示。S01 p.46S01 p.47
  • 事實上是輸入一張照片,輸出三個數字 y1、y2、y3,分別對應土八哥、白尾八哥、家八哥。S01 p.48
  • 生成式 AI 也是這種呆萌型機器人。S01 p.49
  • 現在流行的生成式 AI 有兩類:(1) 圖像生成型 AI,例如 prompt「a rabbit wearing a rabbit ear hat」產生對應圖像;(2) 文字生成型 AI,例如 prompt「請列出五個學習生成式 AI,該注意的重點。」得到一段文字回覆。S01 p.50S01 p.51

為什麼討論生成式 AI(Generative Models)

  • 大家最初討論 Generative Models 的原因有三:(1) 當然主要就是讓電腦創作;(2) 還有面子問題:1950 年,在還沒有現代電腦的年代,圖靈就問了「有沒有可能和對方用無線打字機對話,我無法分辨對方是真人還是機器」;(3) 我們相信真的要懂就要能創造,引用費曼「What I cannot create, I do not understand.」S01 p.52S01 p.53S01 p.54S01 p.55

Colab 與 Jupyter 操作

  • Colab 是 Google 的雲端運算系統:不用安裝,Google 帳號登入即可使用,免費可用 GPU 或 TPU。S01 p.57
  • Colab 可以說是雲端版的 Jupyter Notebook;Jupyter 支援 Python、Julia、R,原本叫 IPython Notebook;原作者為 Fernando Pérez。S01 p.58S01 p.59
  • 新增筆記本來寫程式有兩種方法:方法 1(p.60,文字層無說明文字),方法 2 是從「檔案」選「在雲端硬碟中建立新筆記本」。S01 p.60S01 p.61
  • 使用老師(或別人)的 GitHub 程式:選 GitHub 標籤,輸入 yenlung;讀入程式後在「檔案」選擇在雲端硬碟中儲存副本。S01 p.62S01 p.63
  • 基本設定:在「工具 > 設定 > 編輯器」可反勾選程式碼完成建議以去除干擾,縮排寬度建議改成 4;另有「療癒設定」(柯基、貓咪、螃蟹模式,讓動物陪你寫程式)。S01 p.64S01 p.65S01 p.66
  • 在「編輯 > 筆記本設定」可開啟 GPU,可選 GPU 或 TPU。S01 p.67S01 p.68
  • 每個 cell 最重要的動作是按 shift-enter 執行。S01 p.69
  • Colab 的 AI 輔助系統:最標準用法、像 ChatGPT 等大型語言模型一樣提問、Colab 會預測你要做什麼並可在註解中提示。S01 p.70S01 p.71S01 p.72
  • 魔術指令以 % 開頭:%cd、%save、%run、%timeit 等;標準魔術指令為 %matplotlib inline(圖直接顯示在網頁)。S01 p.74S01 p.75
  • 標準套件三個:numpy、matplotlib、pandas,以 import numpy as np、import pandas as pd、import matplotlib.pyplot as plt 引入。S01 p.76
  • 驚嘆號 ! 可直接下系統指令(例如 !pwd),平時少用但課程會用到。S01 p.77
  • plt.plot 是畫圖王牌指令:plt.plot(X,Y) 的 X 是點的 x 座標 list(array),Y 是點的 y 座標 list;例如 plt.plot([3,-5,7,2]) 畫出 (0,3),(1,-5),(2,7),(3,2) 並連線。S01 p.80S01 p.81S01 p.82
  • 點的兩種表示法:points = [(0.8, 2), ...](左邊)與 X、Y 分開(右邊);互換靠 zip:list(zip(X,Y)) 得到點的 list,X, Y = zip(*points) 做 unzip,且 unzip 其實就是 zip、邏輯一樣。S01 p.83S01 p.84S01 p.85S01 p.86
  • 求助方式:print? 再 shift-enter 可以,但「很遜」;更好的是打到一半按 shift-tab 出現說明,按兩次出現完整說明。S01 p.88S01 p.89
  • TAB 神鍵:最基本的補完功能;\pi + TAB(LaTeX 語法)可快速打出希臘字母(可當變數名稱)。S01 p.90S01 p.91S01 p.93
  • Markdown 筆記:從選單選 Markdown 格式或按 CTRL-M 進入 meta 狀態,再按 M 切換為 Markdown 模式、Y 切回 Code 模式,L 顯示/隱藏 line number,F 搜尋/置換。S01 p.95S01 p.96
  • Markdown 語法:# 標題、* 條列、[文字](網址) 超連結、![說明](bear.png) 插入圖片、支援 LaTeX 數學式(如 $f(x)=x^2$、$$\int_a^b f(x)\,dx$$)。S01 p.97S01 p.98S01 p.99S01 p.100S01 p.101
  • ipywidgets 互動:from ipywidgets import interact;寫個函數就可以互動,interact(f, x=3) 等;一個資料型態就對應一種互動(整數、浮點數滑桿、list 對應下拉式選單);可給預設值、範圍如 n=(1,50);可做視覺化互動(例如 np.sinc(n*x) 配合 interact(draw, n=(1.,10.)))。S01 p.103S01 p.104S01 p.105S01 p.106S01 p.107S01 p.108
