02 呆萌型 AI 機器人:神經網路與函數學習機

來源:raw/02神經網路的概念.pdf(共 123 頁投影片)。

主題

把 AI 模型比喻成「呆萌型 AI 機器人」,本質是一台「函數學習機」 f_θ:只要告訴它輸入是什麼、輸出長什麼樣子,再給大量有正確答案的數據,它就靠調整參數 θ(以 gradient descent 最小化 loss function)學出一個函數。內容涵蓋輸入/輸出的數字化(tensor、one-hot、softmax)、神經元與 DNN 的建構、loss function、gradient descent,最後以 TensorFlow/MNIST 實作第一個神經網路。

重點

  • 現代 AI 模型只是「呆萌型 AI 機器人」:不會自己知道要做什麼,需要我們告訴它輸入是什麼、輸出是什麼;不會分析、沒有意識、不知道自己在做什麼。S02 p.3
  • 呆萌型 AI 機器人又稱 AI 模型、函數學習機(符號 f_θ),就是知道輸入是什麼、輸出長什麼樣子。S02 p.4
  • 輸入和輸出都需要是數據(一堆數字)。S02 p.5
  • 預測股價漲跌的例子:輸入是過去 20 天的數據,輸出是 y1(漲)、y2(跌)。S02 p.7
  • 即使目標相同,每個人想法不同:每天可取開盤、收盤、…、最低等 N 個特徵,20 天總共 20×N 個特徵。S02 p.8
  • 輸入或輸出更精確地說是張量(tensor):純量(如 x=9487)為 0 階、向量(如 [9,4,8,7])為 1 階、矩陣為 2 階 tensor。S02 p.9
  • 圖片有時是 3D 矩陣(R、G、B 三個通道)。S02 p.10
  • 台灣常見三種八哥(土八哥、白尾八哥、家八哥)辨識:輸出是三個數字,分別代表各八哥的「分數」。S02 p.11
  • 輸出類別以數字表示:1、2、3 對應三種八哥,常做成 one-hot encoding,如土八哥為 [1,0,0]、白尾八哥 [0,1,0]、家八哥 [0,0,1]。S02 p.12
  • 需要準備很多有正確答案的數據(每張照片配上 one-hot 標籤)去訓練。S02 p.13
  • 訓練好後,輸出例:y1=1.9(土八哥)、y2=1.1(白尾八哥)、y3=0.2(家八哥),電腦判斷最有可能是土八哥。S02 p.14
  • 一般會用 softmax:把三個輸出轉成 0.61、0.28、0.11,加起來等於 1,即 61% 土八哥、28% 白尾八哥、11% 家八哥。因輸出可能是小於 0 的負數,softmax 先把數字都轉成大於 0,再按比例分配。S02 p.15
  • Softmax 的目標:把任意 a, b, c 三個數字轉成 p1, p2, p3,保持大小關係,且 p1+p2+p3=1。S02 p.16
  • Softmax 流程:每個數字先經指數轉換得 e^a、e^b、e^c,令 s=a'+b'+c',再按比例得 a'/s、b'/s、c'/s。S02 p.17
  • 如果全部都是正的,直接令 S=a+b+c,α=a/S、β=b/S、γ=c/S 就容易;但不一定為正,所以先做指數轉換。S02 p.18–19
  • 因為輸出加起來等於 1,常有人說我們學的是一個機率分佈 P_θ(講者註明這種說法嚇人的成分居多)。S02 p.20
  • 更嚇人的說法:P_θ(y | x),x 為八哥照片、y 為 (y1, y2, y3)(土、白尾、家八哥)。S02 p.21
  • 可寫成條件機率:P_θ(y = y_i | x = x) = p_i,或 P_θ(y_i | x) = p_i。S02 p.22
  • 深度學習最重要的是「問個好問題」;深度學習專注在「我們怎麼問這個問題」,整個判斷由電腦做,所以一般要大量資料。S02 p.23
  • 深度學習讓電腦「自己看著辦」,需要大量訓練資料,例如 1 個類別大概需要看 1,000 張照片。S02 p.24
  • 電腦不知道這是「家八哥」,只知道這是第 3 類數據;電腦不知自己在做什麼,只依經驗來輸出。S02 p.25
  • 講者列出五個掌握 AI 的 Dive Points:(1) 為什麼說 AI 只是「呆萌型 AI 機器人」;(2) 你想要呆萌一布,學哪一個函數;(3) 為什麼說 LLM 生成的都是「幻覺」;(4) 解釋「AI Agents 就是教 AI 怎麼用我們的方式做事」;(5) AI 落地為什麼領域專家才是關鍵。S02 p.26
  • 現在 AI 紅的原因是深度學習有很多突破性發展,深度學習的核心是神經網路。S02 p.28
  • 用神經網路打造呆萌型 AI 機器人:神經元是神經網路的基本運算單元;基本上就是建幾個隱藏層,每層放上若干神經元,放法差不多 3+1 種:DNN(標準全連結)、CNN(圖形辨識很強)、RNN(有記憶的結構)、Transformers。S02 p.30
  • 隱藏層基本上三種選擇:全連結層(Dense,DNN)、卷積層(Conv,CNN)、遞歸層(LSTM、GRU,RNN);基本上只是神經元的連結方式不同,神經元是基本運算單元。S02 p.31
  • 不管哪種神經網路,神經元是基本運算單元,每個神經元的運算方式是一樣的。S02 p.32
  • 神經元:接受若干個刺激輸入,送出一個刺激輸出。S02 p.33
  • 神經元運算第一步:先算總刺激 w1x1+w2x2+w3x3;w1, w2, w3 稱為權重,是學來的。S02 p.34
  • 第二步:加上偏值(bias)做基準調整,得 Σ w_i x_i + b;權重、偏值都要經過學習得到。S02 p.35
  • 第三步:前面的計算都是線性的,即使經過所有神經元算還是線性的,因此需經過激發函數 φ(activation function)轉換再送出:φ(Σ w_i x_i + b) = h。S02 p.36
  • 要學習的參數為 θ = {w1, w2, w3, b}。S02 p.37
  • 有名的激發函數:ReLU(本世紀新寵)、Sigmoid(感覺應該很接近類神經元的動作)、Gaussian(舊時代的懷念,已很少使用)。S02 p.38
  • 深度學習(神經網路)三大天王:DNN(全面考慮的基本型)、CNN(圖形辨識天王)、RNN(有記憶的神經網路)。S02 p.39
  • 以全連結神經網路(DNN)為例,示範如何打造函數學習機;範例是「兩個輸入、一個輸出」的 AI 模型。S02 p.40–41
  • DNN 的一層只需決定有幾個神經元(例如 3 個);「完全連結」是指前一層輸出到下一層每一個神經元。S02 p.42–43
  • 下一層要幾個神經元可隨意指定;隱藏層要幾層也是隨意的。S02 p.44–45
  • 打造 DNN 只需決定兩組數字:幾層隱藏層、每層幾個神經元;層與層之間的神經元完全連結。S02 p.46
  • 把所有要學習的參數(所有權重、所有偏值)合併起來叫 θ = {w1, w2, w3, w4, ⋯, b1, b2, ⋯}。S02 p.47
  • 決定了權重與偏值(即 θ 的值)後,輸入任意數值,神經網路就會吐出一個輸出;函數學習機建造完成。S02 p.48
  • 每一層神經網路把輸入轉為另一個 tensor;第 1 層隱藏層就是放一堆神經元;輸出通常是向量。S02 p.49
  • 上一層的輸出就是下一層的輸入;每層的輸出都可以當成電腦對輸入的理解。S02 p.50
  • 神經網路是個近乎全能的「暗黑」函數學習法;有數學定理(Universal Approximation Theorem)證明「一個隱藏層」的神經網路就能學會你要學的函數。S02 p.51–52
  • 深度學習三巨頭:Geoffrey Hinton、Yann LeCun、Yoshua Bengio。S02 p.53
  • 1992 年台灣有神經網路研討會,當年對神經網路有興趣的人大概都去了(照片由 Jason Tsai 提供)。S02 p.54
  • 神經網路曾「魔法光芒不再」:有一陣子研究計畫若說要研究「神經網路」,計畫還沒送出就可以確定不會通過。S02 p.55
  • 上個世紀神經網路沒有預期成功的原因(Yann LeCun 說):複雜的軟體、大量的數據、電腦計算能力,三大要件當時不具足。S02 p.56
  • 到了現在情況完全不同:要寫個強強的深度學習程式比起上個世紀,真的太容易了。S02 p.57
  • 神經網路架好之後,通常先「初始化」參數值;決定好參數值就會出現一個函數 f_θ,也就是「這個神經網路可以動了」。S02 p.59
  • 未經訓練的模型當然不準:例如對八哥照片輸出 p1=0.16、p2=0.12、p3=0.72(判成家八哥),需要訓練。S02 p.60
  • 訓練(學習):參數 θ 決定了,函數學習機學出的函數就固定了(每張照片會回答什麼就決定了)。S02 p.61
  • 函數空間:用某個機器學習方式打造函數學習機後,需要訓練、調整的參數 θ 都決定了;θ 值一決定函數就決定;就算固定了模型,還是有無限多個可能的函數 {f_θ}。S02 p.62
  • 用 loss function(cost function)計算訓練資料中,呆萌 AI 機器人的答案和正確答案差距多大,希望 loss function 的值越小越好。S02 p.63
  • 訓練資料集 {(x1,y1), (x2,y2), …, (xk,yk)}:輸入 x_i 時正確答案應為 y_i。S02 p.64
  • 任何一組參數 θ 給定一個函數 f_θ,對任意輸入 x_i 都給出 ŷ_i = f_θ(x_i);希望 ŷ_i 與正確答案 y_i 差距越小越好。S02 p.65–66
  • 八哥辨識中三張圖的輸出(如 [0.23, 0.43, 0.34])與 one-hot 正確答案比較。S02 p.67–68
  • 差距計算舉例:(1−0.23)² + (0−0.43)² + (0−0.34)² = 0.89。S02 p.69
  • 定義 loss function 來看神經網路「考古題」時與正確答案差多少。S02 p.70
  • 常見 loss function:L(θ) = (1/2k) Σ_{i=1..k} ‖y_i − f_θ(x_i)‖²,其實就是計算和正確答案的差距,希望誤差越小越好。S02 p.71–72
  • 所謂「訓練」就是想辦法讓 loss 越來越小:L(θ1) > L(θ2) > L(θ3) > ⋯。S02 p.73
  • 目標是找到一組參數 θ*,使 loss function 值 L(θ*) 最小(誤差最小);也就是做出的 f_θ* 和目標函數最接近。S02 p.74, p.77
  • 使用的方法叫梯度下降法(gradient descent);因神經網路的特性,也叫反向傳播法(backpropagation)。S02 p.75
  • 對某個參數 w,調整公式為 w − η ∂L/∂w。S02 p.78
  • loss function L 是所有權重和偏值 w1, w2, b1, … 的函數。S02 p.79
  • 數學家先簡化問題:假裝只有一個參數 w。S02 p.80
  • 電腦如何知道往哪走(找最小值):關鍵是切線;切線斜率 < 0 時指的方向是負向,斜率 > 0 時指的方向是正向。S02 p.83–86
  • 切線斜率指的方向和我們應走的極小值方向相反;事實上切線斜率指的方向正是(局部)極大值的方向。S02 p.87
  • 在 w=a 點切線斜率寫成 L′(a);任意點寫成 L′(w) = dL/dw。S02 p.88
  • 新的 w 值調整為 a − L′(a),一般形式 w − dL/dw,往(局部)極小移動。S02 p.89
  • 有時一次調太大會跑過頭;為避免,乘上一個小的數,叫 Learning Rate(η):w − η dL/dw。S02 p.91–92
  • 參數不只一個時,數學家的做法仍是假裝只有一個參數;範例 L(w1,w2,b1) = (b1+2w1−w2−3)²,初始值 w1=1, w2=−1, b1=2。S02 p.93–95
  • 只保留 w1 這個變數、其他值直接代入,L 當場只剩一個參數:L_w1(w1) = L(w1, −1, 2) = 4w1²;再用單變數調整式 w1 − η dL_w1/dw1 調整。S02 p.96–98
  • 多變數函數假裝只有一個變數的微分叫偏微分,把 w1 調整為 w1 − η ∂L/∂w1。S02 p.99
  • 其實就是一一調整:w1 − η ∂L/∂w1、w2 − η ∂L/∂w2、b1 − η ∂L/∂b1,和之前一個變數一樣的做法。S02 p.100
  • 把三式寫成向量形式,關鍵向量稱為 L 的梯度(gradient),記為 ∇L;調整公式寫成 θ − η∇L,這個方法稱為 Gradient Descent。S02 p.101–103
  • 不管機器學習函數學習機怎麼架、選什麼 loss function,都可以使用 gradient descent 去訓練。S02 p.104
  • 進階討論:很多人說 AI 基本上只是 curve fitting,補足沒學過的點,而且是內插法。S02 p.106
  • 事實上高維度是外插(引 Balestriero, Pesenti, LeCun, "Learning in High Dimension Always Amounts to Extrapolation," 2021)。S02 p.107
  • 實作:用全連結神經網路做手寫辨識(講義附連結 https://yenlung.me/AI01),使用 TensorFlow 這個 Python 套件。S02 p.109–110
  • MNIST 數據集:手寫數字辨識資料(Modified,來自美國國家標準暨技術研究院)。S02 p.111
  • 把問題化為函數:輸入一個掃描的手寫數字,輸出電腦判斷的數字;分類問題常用 one-hot encoding。S02 p.112–113
  • 函數樣貌:輸入是一張 28×28 的圖,「拉平」成 784 維向量;輸出 10 個類別,即 10 維向量;中間是神經網路(函數學習機)。S02 p.114
  • 程式工具:Sequential(標準打造函數學習機的方式)、Dense(全連結隱藏層)、SGD(標準的 gradient descent);另有做 one-hot encoding 的工具。S02 p.116
  • MNIST 資料已分好訓練資料與測試資料。S02 p.117
  • 數據處理:輸入圖像拉平並除以 255 做 normalization,標籤用 to_categorical 做 one-hot。投影片文字寫「訓練資料:拉平、normalization;測試資料:做 one-hot encoding」。S02 p.118
  • 打造模型:兩個隱藏層、各 100 個神經元、用 ReLU 當 activation function;輸出 10 維做 softmax。S02 p.119
  • 編譯設定:loss 選哪個 loss function;optimizer 用 SGD 並設 learning rate;metrics 顯示目前正確率。S02 p.120
  • 訓練:model.fit(x_train, y_train, batch_size=100, epochs=20);batch_size 為 mini batch 的大小、epochs 為訓練次數;這是深度學習的重頭戲。S02 p.121
  • 預測:predict 會是對所有測試資料的預測結果。S02 p.122

關鍵術語

  • 呆萌型 AI 機器人 / AI 模型 / 函數學習機(f_θ):知道輸入是什麼、輸出長什麼樣子的機器,本身不知道自己在做什麼。S02 p.3–4
  • 張量(tensor):輸入/輸出的數據形式;0 階為純量、1 階為向量、2 階為矩陣,圖片可為 3D 矩陣。S02 p.9–10
  • one-hot encoding:類別以只有一個 1、其餘為 0 的向量表示。S02 p.12, p.113
  • softmax:先對各數字做指數轉換,再按比例分配使總和為 1。S02 p.15–19
  • 機率分佈 P_θ / 條件機率 P_θ(y_i | x):softmax 輸出加總為 1,故稱學的是機率分佈。S02 p.20–22
  • 神經元:神經網路基本運算單元,運算為 φ(Σ w_i x_i + b) = h。S02 p.32–36
  • 權重(w)、偏值(bias, b):神經元中要學習的參數。S02 p.34–35
  • 激發函數(activation function, φ):把線性結果轉換再送出,避免整體仍是線性;如 ReLU、Sigmoid、Gaussian。S02 p.36, p.38
  • θ:所有要學習的參數(全部權重與偏值)的集合。S02 p.47
  • DNN / CNN / RNN:全連結 / 圖形辨識 / 有記憶的神經網路;對應 Dense / Conv / 遞歸層(LSTM、GRU)。S02 p.30–31, p.39
  • 隱藏層:神經網路中放一堆神經元的層。S02 p.46, p.49
  • Universal Approximation Theorem:一個隱藏層的神經網路就能學會要學的函數。S02 p.52
  • 函數空間 {f_θ}:固定模型後,隨 θ 變化的所有可能函數,數量無限多。S02 p.62
  • 初始化:神經網路架好後先給參數初始值。S02 p.59
  • loss function(cost function):衡量網路答案與正確答案差距的函數,越小越好。S02 p.63, p.71–72
  • 梯度下降法(gradient descent)/ 反向傳播(backpropagation):調整參數使 loss 變小的方法。S02 p.75, p.103
  • learning rate(η):調整步伐的小數,避免跑過頭。S02 p.92
  • 偏微分:多變數函數假裝只有一個變數時的微分。S02 p.99
  • 梯度(∇L):由各偏微分組成的向量。S02 p.102
  • mini batch / batch_size / epochs:訓練時小批次大小 / 訓練次數。S02 p.121
