# Loss 與梯度下降

## 一句話定義
Loss function 衡量模型答案與正確答案的差距,「訓練」就是用梯度下降法(也叫反向傳播)調整參數 θ 讓 loss 越來越小。[S02 p.63][S02 p.73][S02 p.75]

## 白話解釋
- 神經網路架好後先「初始化」參數,這時未經訓練的模型當然不準,例如對八哥照片輸出 0.16、0.12、0.72,判成家八哥(數值依文字層整理,未以圖片核對)。[S02 p.59][S02 p.60]
- Loss function 就像讓模型寫「考古題」,看它和正確答案差多少。[S02 p.70]
- 梯度下降像「走」向最小值:電腦靠切線斜率知道往哪走;但斜率指的方向其實是(局部)極大值方向,所以要往相反方向走(此點已用圖片核對:投影片原文即如此寫。)。[S02 p.83][S02 p.87]
- 數學家的習慣是先簡化問題:「假裝只有一個參數」。[S02 p.80][S02 p.94]
- 一次走太大會跑過頭,所以乘上一個小數,叫 learning rate。[S02 p.91][S02 p.92]

## 重點
### Loss function
- 訓練資料集為 {(x1,y1),…,(xk,yk)};給定 θ 得函數 f_θ,希望 ŷ_i = f_θ(x_i) 與正確答案 y_i 差距越小越好。[S02 p.64][S02 p.65][S02 p.66]
- 常見 loss(均方差 MSE):L(θ) = (1/2k) Σ ‖y_i − f_θ(x_i)‖²。[S02 p.71][S02 p.72]
- 訓練就是讓 L(θ1) > L(θ2) > L(θ3) > ⋯;目標是找到使 loss 最小的 θ*。[S02 p.73][S02 p.74]
- 固定模型後仍有無限多個可能的函數 {f_θ}(函數空間)。[S02 p.62]

### MSE 的問題與 Cross Entropy / KL 散度
- 八哥例:輸出 [0.6,0.3,0.1] 與 [0.6,0.2,0.2] 對 [1,0,0] 的 MSE 為 0.26 與 0.24,但兩者正確答案得分都是 60%,很多時候「一樣好」(數值已用圖片核對,並手算驗證。[S03 p.62])。[S03 p.62][S03 p.63]
- 資訊量(驚訝指數)I(x) = −log P(x):機率越低資訊量越大。[S03 p.64][S03 p.65][S03 p.66]
- Cross Entropy:H(P,Q) = −Σ y_i log ŷ_i;正確答案為 one-hot 時簡化為 −log ŷ_i,正確答案還說機率很低就扣分。[S03 p.75][S03 p.76][S03 p.77][S03 p.78]
- 它比較真實世界的機率分布 P 與網路用 softmax 得到的 Q,希望越接近越好;分類問題用它更適合。[S03 p.69][S03 p.70]
- 對照:正確答案 [1,0,0],答案 [0.7,0.19,0.11] 與 [0.7,0.3,0] 的 MSE 為 0.14、0.18,但 Cross Entropy 皆為 0.36,因為 Cross Entropy 單純在意正確答案。[S03 p.82]
- Entropy(熵)是訊息量的期望值 H(P) = −Σ p_i log p_i,常被稱「亂度」。[S03 p.72]
- KL 散度 D_KL(P‖Q) = H(P,Q) − H(P),Q = P 時為 0;H(P) 固定,所以 cross entropy 越小 KL 也越小(此段 p.83-85 僅依文字層)。[S03 p.84][S03 p.85]
- 需要學 soft target(如老師模型給的 [0.7,0.25,0.05],即蒸餾)時,該考慮 KL 散度;一般學習用 hard target 如 [1,0,0]。[S03 p.87][S03 p.88]

### 梯度下降
- 單一參數:w − η dL/dw(η 為 learning rate)。[S02 p.89][S02 p.91][S02 p.92]
- 多參數:假裝只有一個變數的微分叫偏微分,逐一調整 w1 − η ∂L/∂w1 等,寫成向量即 θ − η∇L,∇L 稱為梯度。[S02 p.99][S02 p.100][S02 p.101][S02 p.102][S02 p.103]
- 不管函數學習機怎麼架、選什麼 loss,都可以用 gradient descent 訓練。[S02 p.104]
- 實作(MNIST):optimizer 用 SGD 並設 learning rate;`model.fit` 中 batch_size 為 mini batch 大小、epochs 為訓練次數。[S02 p.120][S02 p.121]
- 進階討論:有人說 AI 只是 curve fitting 且為內插,但高維度其實是外插(引 Balestriero 等 2021)。[S02 p.106][S02 p.107]

## 與其他概念的關係
- 被訓練的對象是 [[neural-network]] 的權重與偏值 θ。
- Cross Entropy 評量的是 softmax 輸出的機率分布:見 [[softmax-and-sampling]];語言模型的訓練目標見 [[next-token-prediction]]。
